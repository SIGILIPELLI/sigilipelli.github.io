🐍 Python

Go deeper: Python Mastery Path

What is the difference between a list and a tuple?

Lists are mutable (you can add, remove and change items); tuples are immutable once created. Tuples are slightly faster, can be used as dictionary keys if their items are hashable, and signal "this data shouldn't change".

What are *args and **kwargs?

*args collects extra positional arguments into a tuple; **kwargs collects extra keyword arguments into a dictionary. They let a function accept a flexible number of arguments, and are common in wrappers and decorators.

What is a decorator?

A function that takes another function and returns a new function that adds behaviour around it, without changing its code. Applied with @decorator above a function, for example for logging, caching (@functools.cache) or access checks.

Explain shallow copy vs deep copy.

A shallow copy (copy.copy, list[:]) creates a new outer object but shares the nested objects. A deep copy (copy.deepcopy) recursively copies everything, so changing nested data in the copy doesn't affect the original.

What is a generator and why use one?

A function that uses yield to produce values one at a time, pausing between them. It's memory-efficient for large or infinite sequences because it never builds the whole list in memory.

What is the GIL?

CPython's Global Interpreter Lock lets only one thread execute Python bytecode at a time. Threads still help with I/O-bound work; for CPU-bound work use multiprocessing, native extensions, or the free-threaded builds available in newer Python versions.

How does exception handling work?

Code that may fail goes in try; specific errors are caught in except; else runs if nothing failed; finally always runs (for cleanup). Catch specific exceptions rather than a bare except, and use with for resources.

What are list comprehensions?

A concise way to build a list from an iterable: [x*x for x in nums if x > 0]. They're usually clearer and faster than an equivalent loop with append. Dict and set comprehensions work the same way.

☕ Java

Go deeper: Java Mastery Path

What is the difference between JDK, JRE and JVM?

The JVM runs bytecode. The JRE is the JVM plus the standard libraries needed to run programs. The JDK is the JRE plus development tools like the compiler (javac). Modern Java distributions ship as a JDK.

Why is String immutable?

Immutability makes strings safe to share between threads, enables the string pool (reusing literals), lets hash codes be cached for fast HashMap lookups, and prevents security issues when strings are used for things like file paths.

What is the difference between == and equals()?

== compares references (whether two variables point to the same object); equals() compares logical content as defined by the class. Always override hashCode() when you override equals().

How does a HashMap work internally?

It stores entries in an array of buckets chosen by the key's hash code. Collisions go into the same bucket as a linked list, which becomes a balanced tree when a bucket grows large. It resizes when the load factor (0.75 by default) is exceeded.

Abstract class vs interface?

A class can extend one abstract class but implement many interfaces. Abstract classes can hold state and constructors; interfaces define a contract and can include default and static methods. Use interfaces for capabilities, abstract classes for shared base behaviour.

Checked vs unchecked exceptions?

Checked exceptions (like IOException) must be declared or caught, so the compiler enforces handling. Unchecked exceptions (subclasses of RuntimeException) usually indicate programming errors and don't need to be declared.

What are the four pillars of OOP?

Encapsulation (hiding state behind methods), inheritance (reusing behaviour from a parent), polymorphism (one interface, many implementations), and abstraction (exposing what something does, not how).

What are streams in Java 8+?

A declarative way to process collections with operations like filter, map and collect. Intermediate operations are lazy and run only when a terminal operation is called; streams can also run in parallel.

🟨 JavaScript

Go deeper: JavaScript Mastery Path

What is the difference between var, let and const?

var is function-scoped and hoisted with the value undefined. let and const are block-scoped and can't be used before declaration. const prevents reassignment, but objects it points to can still be changed.

What is a closure?

A function that remembers variables from the scope where it was created, even after that scope has finished. Closures power private state, factory functions and callbacks.

Explain the event loop.

JavaScript runs on one thread. Synchronous code runs on the call stack; finished async work queues callbacks. After the stack empties, all microtasks (promise callbacks) run, then the next macrotask (like a timer). That's why a resolved promise logs before setTimeout(fn, 0).

== vs ===?

=== checks value and type with no conversion. == converts types first, which produces surprises like 0 == '' being true. Use === by default.

What are promises and async/await?

A promise represents a value that will arrive later (fulfilled or rejected). async functions return promises, and await pauses inside them until a promise settles, so async code reads like sync code. Handle errors with try/catch.

How does this work?

It depends on how a function is called: the object before the dot, the new object with new, or whatever call/apply/bind set. Arrow functions don't have their own this; they use the surrounding one.

What is event delegation?

Attaching one listener to a parent element and using event.target to handle events from its children. It works because events bubble up, and it's efficient for long or changing lists.

What are debounce and throttle?

Debounce runs a function only after events stop for a set time (for example, search-as-you-type). Throttle runs it at most once per interval (for example, scroll handlers). Both reduce expensive work.

🗄️ SQL

Go deeper: SQL Mastery Path

Explain the types of JOIN.

INNER JOIN returns matching rows from both tables. LEFT JOIN returns all left rows plus matches (NULLs where none). RIGHT JOIN is the mirror. FULL OUTER JOIN returns all rows from both. CROSS JOIN returns every combination.

WHERE vs HAVING?

WHERE filters rows before grouping; HAVING filters groups after GROUP BY and can use aggregates like HAVING COUNT(*) > 5.

How do you find the second-highest salary?

SELECT MAX(salary) FROM emp WHERE salary < (SELECT MAX(salary) FROM emp); or, to handle ties and the Nth value, DENSE_RANK() OVER (ORDER BY salary DESC) and filter for rank 2.

DELETE vs TRUNCATE vs DROP?

DELETE removes chosen rows, can use WHERE, and is logged row by row. TRUNCATE removes all rows quickly and resets identity in many databases. DROP removes the whole table and its structure.

What is normalization?

Organising tables to reduce duplication and update errors. 1NF: atomic values. 2NF: no partial dependency on part of a composite key. 3NF: no dependency between non-key columns. Reporting systems sometimes denormalize for speed.

What is an index and when can it hurt?

A data structure (usually a B-tree) that speeds up lookups and sorting on columns. Indexes cost storage and slow down inserts and updates, so add them for frequent filters and joins, not every column.

What are window functions?

Functions like ROW_NUMBER(), RANK(), SUM() OVER (...) and LAG() that calculate across related rows without collapsing them like GROUP BY does. They're used for rankings, running totals and comparisons with previous rows.

What does ACID mean?

Atomicity (all or nothing), Consistency (rules always hold), Isolation (concurrent transactions don't interfere), and Durability (committed data survives crashes).

📗 Excel

Go deeper: Excel Mastery Path

VLOOKUP vs XLOOKUP vs INDEX-MATCH?

VLOOKUP looks only to the right and breaks when columns are inserted. INDEX-MATCH looks in any direction and is robust. XLOOKUP (Microsoft 365 and Excel 2021+) does both simply, with exact match by default and a built-in "not found" value.

Relative, absolute and mixed references?

A1 changes when copied; $A$1 never changes; $A1 or A$1 lock only the column or row. Press F4 to cycle through them.

What is a PivotTable used for?

Summarising large data quickly: totals, counts and averages by category, with drag-and-drop rows, columns, filters and slicers, without writing formulas.

How do you remove duplicates?

Data → Remove Duplicates for a one-off clean-up; =UNIQUE(range) for a live list; or conditional formatting → Duplicate Values to highlight them first.

What do SUMIFS and COUNTIFS do?

They add up or count values that meet several conditions, for example =SUMIFS(Sales, Region, "North", Month, "Jan").

What is conditional formatting?

Formatting that changes with cell values, such as colour scales, data bars, icon sets or a custom formula rule, to highlight exceptions like overdue dates or low stock.

What is Power Query?

Excel's built-in tool for getting and cleaning data (Data → Get & Transform). It records steps like merging files, splitting columns and fixing types, so you can refresh with new data in one click.

How do you protect a sheet or workbook?

Unlock input cells (Format Cells → Protection), then Review → Protect Sheet with a password. Protect Workbook stops sheets being added, deleted or renamed. File encryption controls who can open the file.

🧾 Tally Prime & GST

Go deeper: Tally Prime & GST Mastery Path

What are the golden rules of accounting?

Personal account: debit the receiver, credit the giver. Real account: debit what comes in, credit what goes out. Nominal account: debit expenses and losses, credit incomes and gains.

What are the main voucher types in TallyPrime?

Contra (F4), Payment (F5), Receipt (F6), Journal (F7), Sales (F8), Purchase (F9), plus Credit Note and Debit Note (enable these in voucher type settings if hidden).

CGST, SGST and IGST: what's the difference?

For a sale within a state, tax is split equally into CGST (central) and SGST/UTGST (state). For an inter-state sale or export, IGST is charged instead. The place of supply decides which applies.

What is Input Tax Credit (ITC)?

GST paid on business purchases that you can set off against GST collected on sales. You need a valid invoice, the goods or services received, the supplier's invoice showing in your GSTR-2B, the supplier's tax paid, and your return filed.

GSTR-1 vs GSTR-3B?

GSTR-1 reports invoice-level outward supplies (sales). GSTR-3B is the summary return where you declare totals, claim ITC and pay the tax. Monthly filers usually file GSTR-1 by the 11th and GSTR-3B by the 20th; check the portal for current dates.

What is Reverse Charge Mechanism (RCM)?

For certain notified services (like goods transport agency or legal services from an advocate) and some purchases from unregistered suppliers, the buyer pays the GST to the government instead of the supplier.

How do you do bank reconciliation in TallyPrime?

Open the bank ledger, use Reconcile (or Alt+R), enter bank dates for cleared items, then compare the reconciled balance with the statement. Remaining differences are uncleared cheques or bank-only entries like charges and interest.

When is an e-way bill required?

For moving goods worth more than ₹50,000 (the general limit; some states set different intra-state limits). It's generated on the e-way bill portal or from TallyPrime, with transport details, before the goods move.

📣 Digital marketing & SEO

Go deeper: Digital Marketing & SEO Mastery Path

SEO vs SEM?

SEO earns free (organic) search traffic by improving content, technical health and authority. SEM usually means paid search ads like Google Ads. SEO compounds slowly; paid search is instant but stops when spending stops.

On-page vs off-page SEO?

On-page SEO covers what's on your site: content quality, titles, headings, internal links and page speed. Off-page SEO covers signals from elsewhere, mainly quality backlinks, brand mentions and reviews.

What are CTR, CPC, CPA and ROAS?

CTR = clicks ÷ impressions. CPC = cost ÷ clicks. CPA = cost ÷ conversions. ROAS = revenue ÷ ad spend. For example, ₹10,000 spend bringing ₹40,000 revenue is a 4× ROAS.

Explain the marketing funnel.

Awareness (people discover you), Consideration (they compare options), Conversion (they buy or sign up), and Retention or loyalty (they return and refer others). Each stage needs different content and metrics.

What is a good landing page?

One that matches the ad or email promise, has a single clear call to action, shows benefits and social proof, loads fast on mobile, and asks only for the information it needs.

How does Google Ads decide your ad position?

Through Ad Rank, which combines your bid, ad quality (expected CTR, ad relevance, landing page experience), and the expected impact of extensions. Better quality can beat a higher bid.

What is A/B testing?

Showing two versions of a page, ad or email to similar audiences at the same time, changing one thing, and measuring which converts better with enough data to be confident.

Which metrics matter for social media?

Reach, engagement rate, clicks, follower growth and, most importantly, conversions and leads tied to business goals. Likes alone are a vanity metric.

☁️ AWS & cloud

Go deeper: AWS Mastery Path

IaaS vs PaaS vs SaaS?

IaaS gives you raw infrastructure such as virtual machines (EC2). PaaS runs your code while managing the platform (Elastic Beanstalk, Lambda). SaaS is finished software you just use (Gmail, Salesforce).

What are Regions and Availability Zones?

A Region is a geographic area (for example, Mumbai ap-south-1). Each Region has several isolated Availability Zones, which are separate data centres. Spreading across AZs gives high availability.

EC2 vs Lambda?

EC2 is a virtual server you manage and pay for while it runs. Lambda runs functions on demand with no servers to manage, billed per request and duration, and suits event-driven, short tasks.

What are S3 storage classes?

Standard for frequent access, Intelligent-Tiering for unknown patterns, Standard-IA and One Zone-IA for infrequent access, and Glacier tiers for archives. Lifecycle rules move objects between them automatically.

What is IAM and least privilege?

IAM controls who can do what in AWS through users, groups, roles and policies. Least privilege means granting only the permissions needed. Prefer roles over long-lived access keys, and enable MFA.

Security groups vs NACLs?

Security groups are stateful firewalls on instances that support allow rules only. Network ACLs are stateless, apply to subnets, and support both allow and deny rules evaluated in order.

How do you make an application highly available?

Run instances in multiple AZs behind a load balancer, use Auto Scaling, choose managed multi-AZ databases, keep backups, and monitor with health checks and alarms.

What is the shared responsibility model?

AWS secures the cloud itself (hardware, facilities, core services). You secure what you put in it: data, identity and access, configuration, operating systems and application code.

🤝 HR & behavioural round

Go deeper: English Fluency Mastery Path · Resume Tools

Tell me about yourself.

Use present, past, future in 60–90 seconds: what you do now and your strongest skill, one or two relevant achievements with numbers, and why this role is your logical next step. Don't recite your resume.

Why do you want to join this company?

Mention something specific (product, customers, growth, values), connect it to your skills and goals, and show how you'll contribute. Research their website, news and job description first.

What are your strengths and weaknesses?

Give strengths relevant to the role, each backed by an example. For a weakness, choose a real but non-critical one, and explain what you're doing to improve it and what progress you've made.

Describe a challenge you faced. (STAR method)

Situation (context), Task (your responsibility), Action (what you did, specifically), Result (the outcome, with numbers if possible). End with what you learned.

Where do you see yourself in five years?

Show ambition aligned with the role, such as deeper expertise, bigger responsibility or leading projects, without implying you'll leave soon. Focus on skills and impact rather than job titles.

Why are you leaving your current job?

Stay positive and forward-looking: growth, new challenges, a better fit for your skills. Never criticise your current employer or colleagues.

What are your salary expectations?

Research the market range for the role and city first. Give a range based on that research and your experience, and say you're flexible for the right role and total package.

Do you have any questions for us?

Always ask one or two: what success looks like in the first 90 days, how the team works, what the biggest challenges are right now, and what the next steps in the process are.
