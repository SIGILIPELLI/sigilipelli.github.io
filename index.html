Mastery Path is a collection of 98 free, self-paced courses — one per language, platform or discipline — built and maintained by Vinod Bhanuja. Every course follows the same shape: Level 1 through Level 4, each level made of short topic modules with runnable examples, and a hands-on project that ties the level together. There's no signup and no paywall; pick a track below and start at Level 1.

Coverage spans programming languages (Python, Java, Go, Rust, TypeScript and 14 more), cloud platforms, AI/ML and LLM development, data engineering and analytics, embedded systems, security, testing/QA, DevOps infrastructure, and product/engineering leadership — see the full index below.
